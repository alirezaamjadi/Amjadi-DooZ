# بازی Doz (D0Z) Amjadi | Doz (D0Z) Amjadi Game




## معرفی بازی (فارسی)

**نام بازی:** Doz (D0Z) Amjadi  
**سازنده:** علیرضا امجدی  
**سال ساخت:** 2025  
**زبان برنامه‌نویسی:** Python  

### توضیح بازی  
بازی Doz یک نسخه پیشرفته از بازی Tic Tac Toe است که در قالب یک تخته بزرگ شامل ۹ تخته کوچک ۳×۳ اجرا می‌شود (معروف به Ultimate Tic Tac Toe).  
هر بازیکن سعی می‌کند با علامت‌های خود (X یا O) سه خانه متوالی را در تخته‌های کوچک بگیرد و در نهایت با تصاحب سه تخته کوچک متوالی در تخته بزرگ، برنده بازی شود.  

### ویژگی‌ها  
- رابط کاربری گرافیکی با استفاده از Pygame  
- حالت تمام صفحه قابل تغییر  
- قوانین اختصاصی برای پایان بازی در هر تخته کوچک  
- نمایش وضعیت بازی به صورت واضح و زیبا  

### نحوه بازی  
1. بازی شامل یک تخته بزرگ ۳×۳ است که هر خانه آن یک تخته کوچک ۳×۳ است.  
2. بازیکنان نوبتی X و O علامت خود را در خانه‌های کوچک قرار می‌دهند.  
3. برای بردن یک تخته کوچک باید سه علامت متوالی در آن تخته قرار گیرد.  
4. بردن تخته‌های کوچک، همانند بردن خانه‌های تخته بزرگ است.  
5. اگر تخته کوچکی مساوی شود، به صورت تصادفی برنده آن تخته مشخص می‌شود.  
6. بازیکن X با علامت مشکی و بازیکن O با علامت قرمز بازی می‌کند.  
7. امکان تغییر حالت تمام صفحه از منو وجود دارد.  

### اجرای بازی  
- نیازمند نصب پایتون و کتابخانه Pygame  
- اجرای فایل اصلی `python main.py`

### About the Game  
Doz is an advanced version of Tic Tac Toe, played on a big board consisting of nine smaller 3x3 boards (known as Ultimate Tic Tac Toe).  
Players take turns marking X or O aiming to win small boards by lining three marks, and ultimately winning three small boards in a row on the big board to claim overall victory.  

### Features  
- Graphical interface using Pygame  
- Toggle fullscreen mode  
- Custom rules for small board completion  
- Clear and appealing game visuals  

### How to Play  
1. The game consists of a big 3x3 grid where each cell is a small 3x3 Tic Tac Toe board.  
2. Players alternate placing their marks (X or O) in small cells.  
3. To win a small board, get three marks in a row inside it.  
4. Winning small boards is like claiming cells on the big board.  
5. If a small board ends in a draw, a winner is assigned randomly for display.  
6. Player X uses black marks; Player O uses red marks.  
7. Fullscreen mode can be toggled via the menu.  

### How to Run  
- Requires Python and Pygame installed  
- Run the main file with `python main.py`
